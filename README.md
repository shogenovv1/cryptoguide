# CryptoGuide

CryptoGuide — русскоязычная учебная веб-программа для изучения Bybit, P2P, спота, фьючерсов, графиков и управления риском.

## Возможности

- Учебные мини-уроки по P2P, споту, графикам, фьючерсам, риску, ордерам, безопасности и торговому плану.
- RU/EN интерфейс и тёмная/светлая тема.
- Единая лента свежих криптовалютных новостей с оригиналом и переводом.
- Публичные котировки BTC, ETH и SOL с резервным источником.
- Paper-trading, симулированный PNL и учебный журнал.
- Разбор скриншотов через серверный AI Vision-маршрут без подключения к аккаунту Bybit и без автоторговли.

## Запуск локально

```bash
npm start
```

Сервер запускается на `PORT` из окружения или на порту `3000`.

Для AI Vision и перевода новостей сервер использует credentials, доступные только на сервере. Не добавляйте ключи в HTML, JavaScript, Git или README.

## GitHub Pages

GitHub Pages показывает статическую версию интерфейса из корневого `index.html`. В ней доступны учебные уроки, словарь, тема, язык, paper-trading и локальный fallback рынка/новостей. Для живого RSS, серверного AI Vision и полного API используйте опубликованную серверную версию Manus.

## Безопасность

Приложение не хранит ключи Bybit, не подключается к кошельку и не размещает реальные ордера. Все рекомендации являются учебными сценариями, а не финансовой рекомендацией.
